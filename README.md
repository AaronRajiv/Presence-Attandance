# Aura Attendance

Design an ultra-premium iOS attendance tracking app that looks completely native to Apple's latest iOS 26 design language.

This is NOT a Material Design app.

This is NOT Android inspired.

The app should look like it could have been designed by Apple's Human Interface team.

Design philosophy:

• Extremely minimal

• Large breathing space

• Beautiful typography

• Authentic Liquid Glass

• Native Apple spacing

• SF Pro typography

• SF Symbols

• Rounded continuous corners

• Frosted translucent materials

• Soft layered shadows

• Subtle gradients

• Smooth spring animations

• Interactive glass morphing

• Dynamic lighting

• Zero visual clutter

Overall feeling:

Calendar + Health + Wallet + Journal + Reminders.

The app contains four tabs:

Home

Calendar

Statistics

Settings

------------------------------------

HOME

------------------------------------

The home page contains floating squarish Liquid Glass cards.

Each card represents one subject.

Example cards:

System Software and Compiler Design

Network Security

Data Science

Cloud Computing

etc.

Each card contains:

Subject Name

Lecturer Name

Attendance %

Circular attendance progress ring

Next Class

Today's status indicator

Cards have depth, refraction, and dynamic highlights.

Cards gently float.

Cards react to touch with Apple's latest Liquid Glass interaction.

When tapped:

The card morphs into a large floating Liquid Glass window using Apple's spring animation.

No page transition.

The card literally expands into place.

------------------------------------

SUBJECT WINDOW

------------------------------------

Large glass sheet.

Contains:

Large subject title

Lecturer name

Current attendance %

Circular progress

Today's schedule

Next scheduled class

Beautiful monthly calendar

The calendar uses Apple's latest iOS 26 appearance.

Scheduled class days are highlighted.

Present days use green translucent dots.

Missed days use red translucent dots.

Extra classes use blue dots.

Today's date has Apple's native highlight.

At the bottom:

Two large floating Liquid Glass buttons.

Present

Missed

Both have authentic Apple glass appearance.

Large enough for thumb interaction.

Tap animation:

Scale

Ripple

Haptic

Above the calendar:

Floating Add Extra Class button.

This opens another native glass sheet.

------------------------------------

STATISTICS

------------------------------------

Beautiful charts.

Attendance trends.

Weekly attendance.

Monthly attendance.

Subject comparison.

Large percentage rings.

Everything looks like Apple's Health app.

------------------------------------

SETTINGS

------------------------------------

Theme

Accent Color

Export Data

Import Data

Reset Attendance

iCloud Sync toggle

Notification settings

Timetable editing

------------------------------------

ANIMATIONS

------------------------------------

Every transition uses:

Spring physics

Liquid morphing

Shared element transitions

Blur interpolation

Glass refraction

Soft opacity fades

Native iOS timing curves.

No harsh animations.

Everything should feel like an Apple first-party application.

The UI should be almost impossible to distinguish from a real iOS app.
